# Foundations of Machine Learning

A beginner-friendly, industry-standard machine learning course delivered in 1-hour daily sessions, 5 days a week, over 4 weeks (20 hours total). Designed to take a complete beginner from "what is ML?" to understanding and practicing all three core types of machine learning — supervised, unsupervised, and reinforcement learning — and building a simple end-to-end model.

---

## 📌 Course Format

* **Duration:** 4 weeks
* **Schedule:** 1 hour/day, 5 days/week
* **Total Content:** 20 hours (20 sessions)
* **Level:** Beginner (no prior ML experience required; basic computer literacy assumed)
* **Style:** Concept + hands-on practice in every session

## 📅 Course Syllabus

### Week 1: Orientation, Tooling, then ML

| Day | Session Title | Topics Covered |
| :---: | :--- | :--- |
| **Day 1** | **Course Orientation & Expectations** | Course outline walkthrough, learning objectives, daily format (concept + practice), ground rules & etiquette, trainer introductions, open Q&A. |
| **Day 2** | **NumPy Essentials** | What NumPy is and why it matters, arrays vs. plain lists, basic array operations, indexing/slicing, and foundational array manipulation for ML. |
| **Day 3** | **Pandas Essentials & Data Cleaning** | Intro to Pandas, DataFrames vs. Series, reading CSV datasets, selecting rows/columns, handling missing values & duplicates, and basic outlier/pattern visualization. |
| **Day 4** | **Introduction to Scikit-learn** | What Scikit-learn is, the unified `fit`/`predict` API pattern, loading sample datasets, and training a first toy model end-to-end. |
| **Day 5** | **Student Presentation & Revision Day** | Student-led presentations recapping weekly concepts (NumPy, Pandas, Scikit-learn, core ML concepts), trainer Q&A, and misconception corrections. |

> **🎯 Week 1 Outcome:** Students understand the course structure, work comfortably with NumPy arrays and Pandas DataFrames, recognize Scikit-learn's API pattern, and grasp fundamental ML principles.

---

### Week 2: Supervised Learning & Regression Deep Dive

| Day | Session Title | Topics Covered |
| :---: | :--- | :--- |
| **Day 6** | **Simple Linear Regression & Cost Function** | Linear regression mechanics, fitting a line (predicting salary from experience), defining cost functions, and intuitive explanation of MSE vs. MAE. |
| **Day 7** | **Gradient Descent: How Models Learn** | Intuition of "rolling downhill" to minimize error, conceptual weight updates without complex calculus, and visual convergence animations. |
| **Day 8** | **Multiple Linear Regression** | Multi-feature predictions (e.g., salary via experience, education, city), handling categorical data, and one-hot encoding fundamentals. |
| **Day 9** | **Polynomial Regression, Overfitting & Underfitting** | Modeling nonlinear relationships with curves, visual comparison of underfitting vs. optimal fit vs. overfitting. |
| **Day 10** | **Student Presentation & Revision Day** | Student presentations on cost functions, gradient descent, multiple regression, one-hot encoding, and overfitting/underfitting; trainer feedback. |

---

### Week 3: Unsupervised Learning & Feature Engineering

| Day | Session Title | Topics Covered |
| :---: | :--- | :--- |
| **Day 11** | **Feature Engineering & One-Hot Encoding** | Core concepts of features, feature scaling, encoding techniques, and why feature quality outpaces raw data volume. |
| **Day 12** | **Introduction to Unsupervised Learning** | Unlabeled data processing, key use cases, and industry applications (customer segmentation, recommendation grouping). |
| **Day 13** | **Clustering Basics** | K-means clustering intuition, distance-based grouping, and hands-on visual clustering demonstrations. |
| **Day 14** | **Dimensionality Reduction & Anomaly Detection** | Simplifying high-dimensional data (conceptual PCA) and identifying outliers/anomalies (e.g., fraud detection use cases). |
| **Day 15** | **Unsupervised Learning Recap & Mini Exercise** | Guided hands-on exercise: clustering real-world data (e.g., customer purchase behavior) and interpreting cluster insights. |

> **🎯 Week 3 Outcome:** Students distinguish between supervised and unsupervised learning, apply preprocessing/feature engineering, and implement basic clustering pipelines.

---

### Week 4: Reinforcement Learning & Bringing It All Together

| Day | Session Title | Topics Covered |
| :---: | :--- | :--- |
| **Day 16** | **Introduction to Reinforcement Learning** | Core RL definition, differences from supervised/unsupervised paradigms, agent-environment-reward loops, and practical examples (robotics, gaming). |
| **Day 17** | **Core RL Concepts** | States, actions, rewards, and policies explained via analogies (e.g., reward-based habit learning). |
| **Day 18** | **Hands-On Reinforcement Learning** | Guided demo using interactive grid-world/browser-based RL simulations showing agent trial-and-error optimization. |
| **Day 19** | **The ML Project Lifecycle & Mini Project** | End-to-end pipeline: Problem definition → Data prep → Modeling → Evaluation → Deployment awareness; guided capstone mini-project. |
| **Day 20** | **Course Wrap-Up & Next Steps** | Synthesis of all three ML paradigms, common beginner pitfalls, self-study paths, and trainer panel Q&A. |

> **🎯 Week 4 Outcome:** Students grasp conceptual reinforcement learning, understand the complete machine learning lifecycle, and compare all three core ML paradigms.

## 💡 What This Course Covers

* **Core ML Paradigms:**
  * **Supervised Learning:** Linear, multiple, and polynomial regression.
  * **Unsupervised Learning:** K-means clustering, conceptual PCA, anomaly detection.
  * **Reinforcement Learning:** Agent-environment-reward dynamics, state-action spaces, policies.
* **Workflows & Tooling:** NumPy, Pandas, Scikit-learn, and feature engineering fundamentals.
* **Model Mechanics:** Cost functions, gradient descent intuition, overfitting, and underfitting.
* **Lifecycle:** Business framing to model building and deployment awareness.

---

## 🚫 Out of Scope (Deliberate Next Steps)

This course is intentionally focused on solid fundamentals within 20 hours and does not cover:
* Complex calculus or linear algebra mathematical proofs
* Deep Learning and neural network architectures
* Advanced RL mathematics (e.g., Q-learning equations, policy gradients)
* Production cloud deployment, CI/CD, and MLOps tooling
* Gradient boosting internals and hyperparameter optimization libraries
